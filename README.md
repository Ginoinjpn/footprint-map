# 足あと地図 (Footprint Map)

住んだ国・訪れた国・通過した国を、実際の国境線を使った世界地図上に色分けして表示するアプリケーションです。日本国内は都道府県単位でも記録できます。

## 使い方

1. **[アプリケーションを開く](https://Ginoinjpn.github.io/footprint-map/)**
2. 上部の **World / Japan タブ** で世界地図と日本地図を切り替え
3. 地図上の国・都道府県をクリック、または一覧表の **-/T/V/L** ボタンでステータス(未訪問/通過/訪問/居住)を変更
4. 検索・大陸(地方)フィルタ・ステータスフィルタで一覧を絞り込み
5. プロフィール欄の **Edit** ボタンで名前・自己紹介・場所を編集

## 特徴

- 🗺️ **実際の境界線データ** — Natural Earth / 公開されている都道府県境界データから生成した本物の地図
- 🌏 **World / Japan 切り替え** — 同じページ内でタブ切り替え
- 🎨 **ステータス色分け** — 居住(緑)・訪問(オレンジ)・通過(青)を地図と一覧の両方に反映
- 🔍 **検索・フィルタ** — 大陸/地方・ステータスでの絞り込み
- 🔎 **ズーム・パン・全画面表示** — マウスホイール/ピンチ操作、全画面ボタンに対応
- 💾 **記録の保存** — 変更内容はブラウザにのみ保存(サーバー送信なし)
